# Analyzing Economic Data (Practice Project)

## Purpose
Learn how to load, inspect, and structure macroeconomic datasets using Python (Pandas).

## Current Stage
Layer 1 — Data Ingestion & Validation

## What this project does right now
- Loads CPI-style CSV data into a Pandas DataFrame
- Prints basic structure information (head, info, columns, shape)

## Data being used
Simple synthetic CPI dataset with:
- category
- current
- previous

## Goal of next step
Compute changes (MoM differences) and start ranking movements.
